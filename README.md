# AI Resume & LinkedIn Optimizer (India-Focused)

An AI-powered Micro-SaaS that analyzes resumes and LinkedIn profiles against real job descriptions to improve ATS compatibility and recruiter visibility — optimized specifically for the Indian job market.

---

## 🚀 Overview

Modern hiring pipelines rely heavily on **Applicant Tracking Systems (ATS)** and keyword-based recruiter searches.  
A large percentage of resumes are rejected before human review due to poor keyword alignment, weak structure, or irrelevant content.

This project helps job seekers:
- Understand how ATS systems evaluate resumes  
- Optimize resumes for specific job descriptions  
- Improve LinkedIn profiles for recruiter discovery  
- Receive actionable, role-specific rewrite suggestions  

Designed for **students, freshers, and early-career professionals in India**.

---

## 🎯 Target Users

- College students and freshers  
- Professionals with 0–5 years of experience  
- Candidates applying for Indian or remote roles  
- Freelancers transitioning to full-time employment  

---

## ✨ Key Features

### 1. ATS Resume Score (0–100)
- Keyword match against job descriptions  
- Skills relevance analysis  
- Resume structure and formatting checks  
- Role and experience-level fit  

### 2. Keyword Gap Analysis
- Missing must-have keywords  
- Optional or nice-to-have skills  
- Overused or irrelevant terms  

### 3. Section-wise Resume Optimization
- Resume summary improvement  
- Skills section alignment  
- Experience / project bullet rewrites  
- Education and certifications review  

### 4. Bullet Point Rewrites
- Action-verb driven statements  
- Quantified impact where applicable  
- ATS-friendly phrasing  

### 5. LinkedIn Profile Optimization
- Recruiter-optimized headline (220 characters)  
- “About” section rewrite  
- Top recruiter-search keywords  
- India-appropriate networking message template  

---

## 🛠️ Tech Stack

- **Frontend:** React / Next.js (Spark scaffolded)
- **Backend:** Node.js / Serverless Functions
- **AI Engine:** LLM-based prompt orchestration
- **Parsing:** PDF / DOC resume text extraction
- **Deployment:** GitHub Spark

---

## 🧠 How It Works

1. User uploads resume (PDF/DOC)
2. User pastes target job description
3. AI analyzes resume vs job requirements
4. System generates:
   - ATS score
   - Keyword gap report
   - Section-wise rewrite suggestions
   - LinkedIn optimization output
